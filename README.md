\# Networking Labs



A collection of hands-on computer networking laboratories focused on Linux networking, network protocols, traffic analysis, troubleshooting, and network infrastructure.



This repository documents my practical learning journey through reproducible networking experiments using Kathara, Docker, Linux, tcpdump, and Wireshark.



\## Laboratory Index



| Lab | Description | Technologies |

|---|---|---|

| \[LAB 01 — Basic Network Connectivity](labs/01-basic-connectivity/README.md) | Two-host virtual LAN, IPv4 addressing, ARP resolution, ICMP connectivity testing, and packet analysis | Kathara, Linux, tcpdump, Wireshark |



Each laboratory contains its own documentation, configuration files, test results, and relevant evidence.



\## Technologies \& Tools



\- \*\*Kathara\*\* — Virtual network emulation

\- \*\*Docker\*\* — Container-based environments

\- \*\*Linux\*\* — Network configuration and administration

\- \*\*Wireshark\*\* — Packet inspection and protocol analysis

\- \*\*tcpdump\*\* — Command-line network traffic capture

\- \*\*Git \& GitHub\*\* — Version control and project documentation



\## Topics Covered



\- IPv4 addressing and subnetting

\- Ethernet and MAC addressing

\- Address Resolution Protocol (ARP)

\- Internet Control Message Protocol (ICMP)

\- Network connectivity testing

\- Packet capturing and troubleshooting

\- Automated network configuration



\## Repository Structure



The `labs/` directory contains individual laboratory projects.



Each laboratory is intended to be self-contained and reproducible, with a dedicated README explaining its topology, configuration, testing procedure, and results.



\## Learning Goals



This repository is part of my development in IT infrastructure, computer networking, Linux administration, and network automation.



Future laboratories will progressively introduce routing, switching concepts, network services, security, monitoring, and automation.
